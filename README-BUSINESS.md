# 🌟 Mehdi Hashimi - Business Website

## خوش آمدید!

یہ ایک **مکمل Business Company Website** ہے جو `mehdihashimi.com` کے لیے تیار کیا گیا ہے۔

## ✨ خصوصیات

### 📄 صفحات

1. **Home Page** - خوبصورت ہوم پیج جو فوری طور پر توجہ کھینچتا ہے
2. **About Us** - کمپنی کی معلومات اور اعدادوشمار
3. **Services** - تمام سروسز کی تفصیل
4. **Portfolio** - پچھلی کامیابیوں کی نمائندگی
5. **Team** - ٹیم کے ممبرز
6. **Blog** - جدید مضامین اور نکات
7. **Contact** - رابطہ کا فارم

### 🎨 ڈیزائن کی خصوصیات

✅ **Responsive Design** - تمام ڈیوائسز پر بہترین
✅ **Modern UI** - جدید اور صاف انٹرفیس
✅ **SEO Friendly** - سرچ انجن کے لیے تیار
✅ **Fast Loading** - تیز رفتار لوڈنگ
✅ **Smooth Animations** - خوبصورت حرکتیں
✅ **Full Urdu Support** - مکمل اردو میں

### 💾 فائلوں کی ترتیب


## 🚀 استعمال کریں

### آن لائن دیکھیں

1. GitHub میں repository کھولیں
2. `index.html` فائل پر کلک کریں
3. "Raw" یا "View" پر کلک کریں

### اپنے کمپیوٹر پر

```bash
# Repository کلون کریں
git clone https://github.com/shajidabbas7212-coder/Zamana-hussain.git

# business-website branch میں جائیں
cd Zamana-hussain
git checkout business-website

# index.html کو براؤزر میں کھولیں
```

## 📝 مواد تبدیل کریں

### Company کی معلومات

`index.html` میں یہ تبدیل کریں:


## 🌐 Deploy کریں

### GitHub Pages پر (فری)

1. Repository settings میں جائیں
2. "Pages" سیکشن میں جائیں
3. Source میں `business-website` branch منتخب کریں
4. Save کریں
5. `https://shajidabbas7212-coder.github.io/Zamana-hussain/` پر ملے گا

### اپنا Domain جوڑیں

1. Domain خریدیں (GoDaddy, Namecheap وغیرہ سے)
2. DNS سیٹنگز میں GitHub Pages کے DNS ریکارڈز شامل کریں
3. CNAME فائل بنائیں اور `mehdihashimi.com` لکھیں
